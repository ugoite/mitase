# Contribute

`mitase` is self-hosted: the repository uses the same specification and evidence
discipline it asks adopters to use. These pages separate the contributor loop
from the newcomer path.

- [Reviewing changes](./reviewing/index.md) — follow intent, exact targets, and
  verification evidence through a pull request.
- [Maintaining the repository](./maintaining/index.md) — use the checked-in
  Node and merge-queue workflows.
