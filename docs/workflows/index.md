# Workflows

> **Boundary notice:** The Re-Foundation freeze makes specification inspection
> and validation the Mitase product. The Work pages below document the
> transitional alpha runtime and will be retired or moved to an external tool.

Once the model is clear, use the workflow that matches the job in front of
you. Each group below has its own vocabulary and keeps its practical pages
together.

- [Repository](./repository/index.md) — configuration, migration, and fixing a
  workspace that is not ready yet.
- [Work](./work/index.md) — transitional work requests, plans, and the
  command card for bounded repository tooling.
- [Integrations](./integrations/index.md) — VS Code, LSP, and language adapter
  details.
