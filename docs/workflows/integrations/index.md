# Editor and integrations

The core workflow stays in the repository and CLI. These integrations expose
the same model where it is useful during authoring and review.

- [VS Code extension](./vscode-extension.md) — diagnostics, navigation, and
  trace lookups in the editor.
- [LSP guide](./lsp.md) — the intentionally small JSON-RPC surface.
- [Trace adapter support](./trace-adapter-support.md) — language and evidence
  coverage by adapter.
