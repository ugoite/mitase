# Adopt an existing repository

Adoption is not a greenfield tutorial with the names changed. Start by
discovering the repository, then connect one capability to exact implementation
and verification evidence. The example matrix helps you choose a shape without
making a broad ownership claim.

## Pages in this path

- [Existing repository](./existing-repository.md) — inventory first, then add a
  bounded connected capability.
- [Examples and templates](./examples-and-templates.md) — compare the checked-in
  starter layouts.
