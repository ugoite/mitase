# Quality and anti-patterns

The model is not a paperwork exercise. A green validation result is useful only
when the links describe a real capability and its evidence. This section calls
out the tempting shapes that make a repository harder to change.

- [Spec anti-patterns](./spec-antipatterns.md) — recognize vague, stale, or
  over-broad specifications before they become the new baseline.
